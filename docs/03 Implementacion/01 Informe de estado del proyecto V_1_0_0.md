## Historias de Usuario completadas en este Sprint

- HU-01: Registro de clientes y puntos de entrega.
- HU-02: Definición de rutas y secuencia de visitas por zona.
- HU-03: Generación de plan de distribución con cálculo de costo y tiempo estimado.
- HU-04: Visualización básica del mapa de rutas y resultados del cálculo.
- HU-05: Configuración inicial del entorno de desarrollo y despliegue local con Docker.

## Demostración del trabajo completado

Durante la revisión del Sprint 1, se presentó a los stakeholders la versión inicial de la plataforma con:

- interfaz inicial del sistema para la carga de pedidos y clientes;
- backend con endpoints de prueba para gestión de rutas y métricas;
- lógica de optimización base con restricciones de distancia, costo y tiempo;
- estructura del proyecto organizada por frontend y backend;
- despliegue local con Docker Compose y configuración inicial de base de datos PostGIS.

La demostración permitió validar que el alcance del Sprint 1 cumple con la base funcional requerida para continuar con la siguiente iteración, enfocada en mejorar la experiencia del usuario y la integración con datos reales de operación.

## Pendientes
