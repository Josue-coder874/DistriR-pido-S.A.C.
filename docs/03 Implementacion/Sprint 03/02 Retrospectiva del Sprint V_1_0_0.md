## ¿Qué aprendimos?

La trazabilidad entre Jira, código y documentación evita cerrar actividades sin evidencia. La modularización de pantallas reduce acoplamiento y facilita pruebas, revisión y mantenimiento.

## ¿Qué estamos haciendo bien?

- Pruebas automatizadas en backend y frontend.
- CI con GitHub Actions y análisis CodeQL.
- Uso de roles y permisos desde el frontend y backend.

## ¿Qué podemos hacer mejor?

### Procesos
